# Random Mood Generator

A simple and interactive web application built using **HTML**, **CSS**, and **JavaScript** that generates a random mood, emoji, and matching background color each time the user clicks the button.

## Features

- Random mood generation
- Dynamic emoji updates
- Background color changes based on the selected mood
- Emoji bounce animation
- Responsive user interface
- Interactive button hover effects

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```
Random-Mood-Generator/
│── index.html

```

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/random-mood-generator.git
```

2. Navigate to the project directory.

3. Open `index.html` in your preferred web browser.
